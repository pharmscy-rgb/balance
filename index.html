버전: 1.60
파일 형식: ZIP
설치 방식: 압축 해제 후 balance_sticker.exe 실행

사용 전 안내

  • 다운로드한 ZIP 파일의 압축을 먼저 해제해 주세요.
  • 압축 해제 후 폴더 안의 balance_sticker.exe를 실행하면 됩니다.
  • 처음 실행 시 사용자별 설정 파일과 orders.db가 자동 생성됩니다.
